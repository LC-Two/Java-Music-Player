# Java Music Player (Console Edition)

This is the **version 1** of my project "Music Player". 

I am building it to learn about audio processing and application development in java.

Currently, the application runs in the console and utilizes the 'java.sound.sampled' API to load,play,stop, and navigate through '.wav' files.

### Future Updates:

Currently I am learning about javafx and my next major milestone is to upgrade this project from Command Line Interface(CLI) to fully interactive Graphical User Interface(GUI).

### Features:
 
- play and pause audio tracks.
- skip to next or previous songs.
- Graceful Resource handling.

### How to run:

1. Clone this repository.
2. Ensure you have the 'Gintama_ED_25.wav' and 'TheClimnb.wav' files inside the 'src/main/resources/' directory.
3. Compile and run 'MusicPlayerV2.java'.
